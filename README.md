# Movie-App 🎬

A movie search application built with React, Vite, and TMDB API.

## Features
- Search movies
- Filter movies by genre
- Sort movies by popularity and rating
- View movie posters and details

## Technologies
- React
- JavaScript
- CSS
- Axios
- TMDB API

## Run Locally
1. Run `npm install`
2. Create a `.env` file with your TMDB API key.
3. Run `npm run dev`
